Deploy a Website
from a Claude Chat

Learn how to connect the Netlify MCP, prompt Claude to write HTML, and ship a live site — without leaving the conversation.

4 steps
~10 min
0 terminal required
⚡

Before You Start

  • A Claude.ai account (any paid plan gives you connectors)
  • A free Netlify account at netlify.com
  • No coding experience needed — Claude writes the code
The Walkthrough
1
Connect Netlify to Claude
Setup

Claude can talk directly to Netlify through something called an MCP connector — think of it as giving Claude a plugin that lets it actually push code to a live server on your behalf.

claude.ai → Settings → Integrations

2
Start a New Chat
Connect

Open a fresh chat with Claude. You don't need to do anything special to activate the Netlify connector — Claude detects it automatically and will use it when your prompt calls for a deployment.

1
Click New Chat on the claude.ai sidebar — connectors are active in every conversation automatically
2
You can optionally type: "What Netlify tools do you have available?" — Claude will list what it can do before you start
3
Claude will respond with its Netlify capabilities: reading projects, deploying sites, managing env vars, and more
3
Ask Claude to Build Your Site
Prompt

This is where the magic happens. Give Claude a description of what you want — it will write a complete, single-file HTML page. Be as simple or as specific as you like. Here are two example prompts that work well:

Simple Starter Prompt
Write me a single-file HTML page that is a simple personal landing page. It should have my name, a short bio section, and three links. // Style it cleanly — dark background, modern font, nothing fancy.
Detailed Custom Prompt
Write a single self-contained HTML file for a small business landing page. Include: - A bold headline with a tagline - A 3-column services section - A contact form (no backend needed, just the UI) - Footer with copyright // Use only inline CSS and vanilla JS. No frameworks. No external files. // Make it mobile responsive.
You
Write me a single-file HTML personal landing page with my name, a short bio, and three links. Dark background, modern font.
C

Claude will return a full block of HTML code. You can ask it to revise anything — colors, layout, copy — before deploying.

4
Ask Claude to Deploy It
Deploy

In the same chat, once you're happy with the code, tell Claude to deploy it. It will use its Netlify connector to create a new project and push your file live. No terminal. No GitHub. Just the chat.

Deploy Prompt
Great, I love it. Now deploy that HTML file to Netlify as a new site. // Claude will create the project and give you the live URL.
1
Claude calls the Netlify connector in the background — you'll see a brief note like "Deploying to Netlify..."
2
Within 30–60 seconds, Claude returns a live URL — something like your-site.netlify.app
3
Click the link. Your page is live on the internet. You can share it immediately.
4
Want changes? Just say: "Update the headline to say X and redeploy" — Claude will revise and push again

Pro Tips
🔁

Iterate in the Same Chat

Every edit and redeploy happens in the same conversation. Claude remembers the code it wrote — just describe what to change.

📋

Single File = Simple Deploy

Ask Claude specifically for a "single self-contained HTML file." It keeps all CSS and JS inline — Netlify can deploy one file instantly.

🏗️

Check Your Netlify Dashboard

Every deploy shows up in your Netlify account at netlify.com. You can manage custom domains, analytics, and form submissions there.

🔐

Claude Needs Your Permission

Claude can only do what the Netlify connector allows — and only because you authorized it. You can revoke access in Settings at any time.
